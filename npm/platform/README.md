# @PACKAGE@

The `ahasend` binary of the [AhaSend CLI](https://www.npmjs.com/package/@ahasend/cli)
for @SYSTEM@.

Do not install this package yourself. Install the CLI instead, and npm adds
the binary package for your system:

```bash
npm install -g @ahasend/cli
```

See the [AhaSend CLI documentation](https://ahasend.com/docs/cli) for how to
use it, and the [installation guide](https://ahasend.com/docs/cli/installation)
for other ways to install it.
